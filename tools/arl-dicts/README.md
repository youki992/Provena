# ARL reconnaissance data

These dictionaries and the `webapp.json` fingerprint rules are adapted from the
`ARL-Web-Alone-main` archive supplied with this project. They are used by
`tools/arl_recon.py` for stateless subdomain enumeration, directory discovery,
and web fingerprint matching.

The original ARL project is GPL-licensed. Keep its license and attribution when
redistributing these data files.
