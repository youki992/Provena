# Provena v0.1.0

发布日期：2026-08-28

## 本次更新

- 抓包分组选择支持模糊搜索，可搜索主机、路径、分组名称与指纹。
- 新增“全选当前筛选”和“清空”操作；切换搜索条件不会丢失隐藏的已选分组。
- 抓包详情改为页面内展开查看请求与响应，替代原有弹窗展示。
- 优化抓包页的配置卡片、运行状态、分组列表和暗色主题表现。
- 右上角入口改为 Provena 团队官网：https://github.com/chobits02/provena
- 对话输入区将抓包分组收纳到独立按钮和向上弹出的筛选面板，输入框不再被挤压。
- Pi Agent 标识固定在输入工具栏内，移除 Eino 模式选择并强制使用当前 Pi Agent 执行链。
- Windows 发布包改名为 Provena，并内置便携 Node.js 与 Pi Agent，无需使用者单独安装。
- 修复抓包分组弹层向左超出聊天区域后被裁切的问题，并根据可用空间自动调整展开方向和宽度。
- 修复 8080 端口冲突时先显示 `ONLINE`、随后启动失败的误导性状态；现在仅在端口成功监听后显示在线。
- 端口冲突错误会明确提示检查其他程序或已运行的 Provena 实例。

## 已验证

- 抓包相关服务测试通过。
- 抓包范围筛选与 Pi 路由测试通过。
- 前端脚本和中英文语言文件校验通过。

## 升级提示

本版本未修改数据库结构。升级时仍建议备份 `config.yaml` 和 `data/`，并使用本包中的程序和 Web 资源替换旧版本。
